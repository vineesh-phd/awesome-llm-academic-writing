# Tools and Libraries

- **Zotero** — free, open-source reference manager for collecting, organizing, and citing sources. [Link](https://www.zotero.org/)
- **Semantic Scholar API** — programmatic search over 200M+ papers with citation graphs; used throughout this repository to verify candidate references. [Link](https://api.semanticscholar.org/)
- **Crossref API** — authoritative DOI metadata lookup; the first stop for confirming a citation's title/authors/year actually match its DOI. [Link](https://www.crossref.org/)
- **scite.ai** — citation-context analysis showing whether a citing paper supports, contrasts with, or merely mentions a source — directly useful for claim-citation entailment checks. [Link](https://scite.ai/)
- **Grammarly** — AI-assisted grammar and style checking; one of the writing-assistance tools whose broader category (LLM-based editing aids) this repository's paper examines for homogenization risk. [Link](https://www.grammarly.com/)
