# GitHub Implementations

- **AutoSurveys/AutoSurvey** — [Link](https://github.com/AutoSurveys/AutoSurvey)
  Official implementation of the AutoSurvey paper (Wang et al., 2024): retrieval, parallel section drafting, and iterative refinement for automated literature-survey generation. Actively documented with example scripts.

- **microsoft/hallucinatedreferences** — [Link](https://github.com/microsoft/hallucinatedreferences)
  Official replication code for Agrawal et al.'s "Do Language Models Know When They're Hallucinating References?" — the consistency-check methodology this repository's ethics/integrity category draws on.

- **eric-mitchell/detect-gpt** — [Link](https://github.com/eric-mitchell/detect-gpt)
  Official implementation of DetectGPT (Mitchell et al., 2023), a zero-shot machine-generated text detector using probability curvature — a foundational baseline for any AI-text-detection work relevant to this topic.

- **openai/gpt-2-output-dataset** — [Link](https://github.com/openai/gpt-2-output-dataset)
  OpenAI's official release of GPT-2 outputs plus the RoBERTa-based "GPT-2 Output Detector," one of the earliest and most widely cited AI-text detectors, still used as a baseline in current detection research.

- **huggingface/transformers** — [Link](https://github.com/huggingface/transformers)
  The standard open-source library for working with transformer-based LLMs; underlies most of the writing-assistance and detection tools discussed in this repository. Extremely active maintenance and documentation.
